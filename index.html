书库
添加到主屏幕，像 App 一样用
点浏览器的「分享」按钮 →「添加到主屏幕」。 不添加的话，Safari 可能在 7 天不打开后清除书库和卡片。

首次使用请先点右上角的齿轮图标，填写 AI 服务的 API key

    书库是空的

    点「添加书籍」从设备里选择 EPUB 文件。书会保存在这台设备上，以后直接点开就能接着读。

    阅读时：长按选词查释义，点屏幕左右两侧或左右滑动翻页

    卡片

    iPhone 导入 Anki：点「导出到 Anki」→ 选「存储到文件」→ 打开「文件」App， 长按这个 .csv 文件 →「打开方式」→ 选 Anki。（直接点文件会用别的 App 打开）

    浏览器存储不可用：卡片只保存到关闭页面为止。
